# AppTrace Widget Catalog

AppTrace features 14 modular desktop widgets:

1. **CPU Monitor:** Total and per-core processor utilization, active core count, and history.
2. **Memory Monitor:** Physical RAM allocation, available memory, swap usage, and GiB demand history.
3. **Network Traffic:** Real-time incoming (RX) and outgoing (TX) throughput rates.
4. **Network Hosts:** Active remote IP endpoints, socket frequencies, and protocol breakdown.
5. **Connection Monitor:** Live TCP and UDP socket table with PID and process attribution.
6. **Application Traffic:** Network socket allocation grouped by executable.
7. **Process Explorer:** Process table with PID, PPID, CPU %, RAM, and executable paths.
8. **Top Applications:** Highest CPU and memory consuming processes on the system.
9. **Filesystem Activity:** Observed file creation, modification, and deletion events.
10. **System Health:** Collector status, privilege tokens, drop counters, and capability indicators.
11. **Storage Monitor:** Mounted disk volumes, total capacity, and free space margins.
12. **Alerts Center:** Warning thresholds for CPU, memory, and telemetry ring-buffer drops.
13. **Event Timeline:** Chronological unified telemetry feed with category filters.
14. **Dependency Graph:** Interactive force-directed topology of processes and remote endpoints.
